## 1. Implementation Progress

Our group has completed the main programming requirements for Checkpoint 1. We implemented the packet encoding and validation, sender, and receiver programs using C++. The programs compile successfully, and the required checkpoint tests have passed.

### Build and Command Lines – Complete

Both `fielddrop-send` and `fielddrop-recv` compile successfully using `make`. The programs accept the required command-line arguments and return error messages when invalid arguments are provided.

**Evidence:** `Makefile`, `source/sender.cpp`, and `source/receiver.cpp`.

### Packet Encoding and Validation – Complete

We implemented the 20-byte packet header, packet types, sequence numbers, network byte order, and CRC-32 error detection. The packet encoder was tested against the published ABC packet examples. The generated bytes and CRC-32 values matched the expected results.

**Evidence:** `source/fielddrop_packet.hpp`, `tests/vector_check.cpp`, and `evidence/packet_vector_check.txt`.

### Normal Stop-and-Wait Transfer – Complete

The sender and receiver communicate using the required HELLO, DATA, ACK, FIN, and FIN_ACK packets. The sender transmits one DATA packet at a time and waits for the matching acknowledgment before continuing.

The programs successfully transferred empty files, small text files, binary files, and files requiring multiple packets.

**Evidence:** `source/sender.cpp`, `source/receiver.cpp`, and the test results in `evidence/`.

### File Guards – Complete

The sender rejects files larger than 262,144 bytes before transmission.

The receiver also checks whether the requested output file already exists. If it does, the receiver rejects the transfer without changing the existing file.

**Evidence:** `evidence/sender_case_15.txt`, `sender_case_16.txt`, `receiver_case_15.txt`, and `receiver_case_16.txt`.
